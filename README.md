Resources used to scrape together this implementation (work in progress):
 - [RGBDS](https://rgbds.gbdev.io/docs/v1.0.1/gbz80.7#LD_r8,_HL_)
     - A critical reference for the CPU instructions.
     - Details what each instruction does, what they don't do, how many cycles each one takes etc.
 - [Pan Docs](https://gbdev.io/pandocs/#foreword)
     - All things Game Boy Color, contains the overview of each GB model.
     - Specifies the RAM, ROM, I/O, CPU architecture (and a lot more).
